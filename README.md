## 🚀 Summary

Finding a way to recycle one use plastic.  
Plastic can be reused to make what ever you can imagine.

HDPE (Milk Bottles) and Pet (Coke Bottles) are the most easy to work with.
This waist plastic can be turned into re-mix and then reused to make what ever you can imagine.

You need to
 - Clean it
 - Cut it up
 - Heat it
 - Shape it, normally via a mould

Re-Mix can be put in an Extruder and used with a mould to make objects or into a open ended mould and make Beams, Angels, Rounds and many other things.

Extruded plastic beams can be used to make a picnic table and more

It can be worked and finished with wood working tools ie. Power tools like wood thickness planer lathe etc

Examples made using a Toasted Sandwich maker

The best and easiest entry point is to use a Toasted sandwich maker and a basic mould eg a pie dish
 - The plastic bottles should be cut into strips. Caps can be used as is.
 - Melt plastic in Toasted sandwich maker add plastic until you have require quantity of melted plastic
 - Remove and place in pre-setup mould, must move fast with good gloves
 - Clamp mould and wait

See Brothers Make https://www.youtube.com/@BrothersMake for good examples of the sandwich maker procedure

## 📦 ZoE - Shredder of Extruder - A Plastic Recycling machine
With a need for a Shedder and an Extruder and no budget we combined the two machines into one

A Morrison Electric garden shredder is used as the main motor

ZoE has slip jaw chuck allowing the Extruder screw to be disengaged as required

A RPi5 is used to provide 3 PID controlers, controling Heater element(3) via SSR(3), and Thermocouple(3) process feed back

This set up allows granulation of plastic milk bottles etc into regrind. 

Then melting and extruding into a mould

At the Extruder nozzle a closed mould can be attached or a open mould like a square tube, this produces a plastic beam
